## Documentation rule

Documentation must distinguish among verified, derived, provisional and experimental evidence. Missing information is recorded explicitly rather than inferred or invented.

Runtime paths, physical models, numerical parameters and reference-case outputs are outside the scope of documentation-only cleanup.
