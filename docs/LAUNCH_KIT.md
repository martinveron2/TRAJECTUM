# TRAJECTUM Launch Kit

This page contains concise, technically grounded copy for sharing TRAJECTUM without overstating validation or maturity.

## LinkedIn

**TRAJECTUM — Aerospace Engineering & Flight Simulation Platform**

I’ve been developing TRAJECTUM as an open engineering platform for experimental rocket analysis and technical design workflows.

Current scope includes:
- vehicle geometry and mass properties,
- CG / CP and static stability,
- RK4 trajectory simulation,
- variable mass and thrust-curve integration,
- atmosphere and aerodynamic drag,
- recovery modelling,
- engineering evidence and reproducible validation workflows.

The current CDR reference case has been independently cross-checked against RocketPy under matched first-order assumptions. This is verification evidence, not experimental flight validation.

**Mobile engineering workflow: ready**  
**Desktop interface: in development**

Live demo: https://trajectum-vercel.vercel.app  
Repository: https://github.com/martinveron2/TRAJECTUM  
Engineering review: https://github.com/martinveron2/TRAJECTUM/issues/52

Technical criticism is welcome. If you genuinely find the project useful or promising, a GitHub star is appreciated.
