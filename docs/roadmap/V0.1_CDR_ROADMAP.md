# TRAJECTUM v0.1.0-cdr Roadmap

## P0 — CDR critical path

1. Freeze vehicle geometry and fin geometry.
2. Freeze current-design component masses and datum positions.
3. Compute and independently verify CG.
4. Compute first-order Barrowman CP with documented validity limits.
5. Run trajectory/apogee/MaxQ with explicit motor and Cd assumptions.
6. Synchronize canonical parameters into Fusion 360.
7. Produce validation evidence and CDR-ready outputs.

## P1 — Product foundation

- API contracts for projects, vehicles, simulations, jobs and results.
- reporting contracts for CDR/FRR/LRR/PFR.
- web shell for parametric editor, 3D and result visualization.
- reproducible reference cases.

## P2 — Scale-up

- OpenRocket / RocketPy cross-validation.
- Monte Carlo uncertainty.
- recovery model.
- telemetry / digital twin.
- 6DOF where justified by validation need.

## Definition of done for v0.1.0-cdr

Every engineering result must be traceable through:

`result -> model -> inputs -> source -> assumptions -> validity -> version -> test`
